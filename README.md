# BADWOLF Socket Server — docs site

The public documentation site for **BADWOLF Socket Server**, a scriptable
TCP + UDP endpoint with a real-time dashboard (Tauri 2 · Rust · Tokio).

This repository holds **only the static documentation pages** (HTML + CSS),
published via GitHub Pages. The application source and releases live
elsewhere.
