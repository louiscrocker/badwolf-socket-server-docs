Who it is for

Learn the wire by watching it happen

🖥

Developers

Writing a client and need to see what it actually sends and gets back.

  • Live message stream in text and hex
  • Per-client byte and message counters
  • Scripted replies so the server behaves like the real thing
  • TCP or UDP, four framings, no code change
🎓

Instructors & students

A dashboard that makes connect → send → broadcast → disconnect visible to a room.

  • One-click scenario presets
  • Record a session, replay it in class
  • Throughput chart and structured syslog
  • Pairs with Pcapsule for the packet-level view
🔌

Lab builders & bench engineers

A throwaway endpoint that logs what hit it and can be scripted to answer.

  • Auto-responder: match a line, send a reply
  • Hex view and binary framing for real devices
  • Timed feeds, including a built-in geo stream
  • Instant kick, direct send, token auth

⚠ Honest scope

It is a single-host tool, and that focus is the point. It is not a load generator, a protocol analyser, or an API client — it's the endpoint those tools talk to, and the one place you can watch the whole exchange happen.

Get it

One binary. Nothing to install alongside it.

Windows MSI or NSIS installer, or build from source with npm run build. Cross-platform by design on Tauri.
